# 多言語翻訳ツール

[English](../README.md) | [中文](README_ZH.md) | [日本語](README_JA.md) | [Français](README_FR.md) | [Deutsch](README_DE.md) | [한국어](README_KO.md)

---

AI搭載のデスクトップ翻訳ツール。複数のAPIプロバイダーをサポートし、グローバルホットキー(スペースキー3回タップ)で翻訳を実行します。

- **動作方法**: テキストをコピー → スペースキー3回タップ → 自動翻訳と置換
- **対象プラットフォーム**: Windows 10/11 (x64)

---

## ✨ 主な機能

- **複数AIプロバイダーサポート**: Google Gemini、Anthropic Claude、OpenAI、および全てのOpenAI互換APIサービスを動的に読み込みます。
- **グローバルホットキー**: ウィンドウを切り替えることなく、任意の入力フィールドでスペースキー3回タップで翻訳を実行できます。
- **インテリジェントキャッシュシステム**: 高性能な2層キャッシュ(メモリLRU + SQLite永続化)により、API呼び出しとコストを大幅に削減します。
- **コンテキスト認識翻訳**: 現在のウィンドウタイトルに基づいて異なる会話コンテキストを区別し、一貫性のある翻訳を提供します。
- **翻訳品質評価**: 翻訳結果の品質を自動的に評価し、品質が不十分な場合にインテリジェントに再試行します。
- **堅牢な非同期アーキテクチャ**: `asyncio`とマルチスレッドモデルを採用し、高性能な並行リクエストとスムーズなユーザーエクスペリエンスを実現します。
- **高度な設定管理**:
  - Pydanticモデルによる厳格な設定検証。
  - プログラムディレクトリが書き込み不可の場合、ユーザーホームディレクトリに自動的にフォールバックします。
- **セキュアな鍵管理**: AES-GCM暗号化ツールを内蔵し、APIキーを安全に保存します。
- **開発者ツール**: モード切り替え、設定のホットリロード、APIヘルスチェック、ネットワーク診断をサポートする機能豊富なランタイムコンソール。
- **堅牢な起動プログラム**: Windows環境でのOpenSSL動的ライブラリの依存関係、高DPI表示、一時ファイルのクリーンアップを自動的に処理します。

## 🚀 コアワークフロー

![デモアニメーション](动画演示.gif)

1.  **翻訳の起動**: ユーザーが任意のアプリケーションの入力フィールドでスペースキーを3回タップして翻訳機能を有効化します。
2.  **テキスト取得**: プログラムはシステムクリップボードから翻訳するテキストを自動的に取得します。
3.  **スマート処理**:
    - **言語検出**: ソース言語を自動的に識別します。
    - **キャッシュクエリ**: まずメモリキャッシュを検索し、次にSQLiteデータベースを検索します。ヒットした場合は直ちに結果を返します。
    - **API呼び出し**: キャッシュミスの場合、設定された順序でAIプロバイダーのAPIを呼び出して翻訳を行います。
    - **品質評価**: APIから返された翻訳結果の品質をスコアリングし、品質が基準に達しない場合は、次に設定されたAPIプロバイダーを自動的に試行します。
4.  **結果の置換**: 最終的な翻訳結果は、ユーザーの現在の入力フィールドに自動的に置換されます。

## 🛠️ 環境とインストール

- **システム**: Windows 10/11 (x64)
- **依存関係**: Python 3.11または3.12、Poetry

**クイックスタート:**

```bash
# 1. 依存関係のインストール
# Python 3.11または3.12環境を推奨
pip install poetry
poetry install
poetry shell

# 2. APIキーの設定(重要なステップ)
# プログラムを起動する前に、少なくとも1つのAPIキーを設定する必要があります
# 以下のコマンドを実行し、メニューの指示に従ってください
poetry run python -m utils.api_key_tool

# 3. プログラムの起動
poetry run python start.py
```

**⚠️ 重要な注意事項:**

- **APIキーは暗号化が必須**: プログラムを起動する前に、`api_key_tool`を使用してAPIキーを暗号化して設定する**必要があります**。暗号化されていない生のキーは受け付けられません。
- **設定ファイル**: プログラムの初回起動時に、`config/`ディレクトリに`config.yaml`、`mode_config.yaml`、`models.yaml`の3つの設定ファイルが自動的に生成されます。必要に応じて変更できます。

## 💡 トラブルシューティング

- **翻訳が起動できない**:
  - `config/models.yaml`に少なくとも1つの暗号化されたAPIキーが設定されているか確認してください。
  - 他のプログラムがグローバルキーボードフックを占有していないことを確認してください。
- **翻訳が失敗する**:
  - プログラム起動後、コンソールでオプション`7`(APIヘルスチェック)を選択し、APIサービスが利用可能か確認してください。
  - `logs/app.log`ファイルで詳細なエラー情報を確認してください。
- **権限の問題**:
  - プログラムが現在のディレクトリに`config`、`logs`、`data`フォルダを作成できない場合、ユーザーホームディレクトリ(`C:/Users/YourUsername/.multitranslator`)に自動的に作成を試みます。これらの場所の少なくとも1つが書き込み可能であることを確認してください。
